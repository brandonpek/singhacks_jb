# Singhacks 2026 — Julius Baer Challenge

## Access Alpha

> AI-superpowered Relationship Managers.

Access Alpha combines portfolio intelligence and relationship intelligence to help Relationship Managers understand client needs, identify relevant opportunities, and take informed action.

### Portfolio Intelligence

Analyzes each client's needs alongside their holistic portfolio, helping the Relationship Manager understand what is happening and where attention may be required.

### Relationship Intelligence

Uses the bank's proprietary relationship network to create practical value for clients. Access Alpha turns portfolio and network signals into AI-powered actions while preserving the Relationship Manager's unique human judgment and personal touch.

## Technical Outputs

### Access Alpha Web Application

- Relationship Manager overview of the entire client portfolio
- Individual client explorer and portfolio view
- Opportunity routes for each client requirement
- Market and current-events intelligence
- Governed network map

### Network Intelligence Infrastructure

- Network database and data schema
- Web crawler for external public relationship data
- Review staging and governance controls for externally sourced relationships
